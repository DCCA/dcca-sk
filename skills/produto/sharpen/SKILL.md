# Sharpen

Adapted from pstack's `sharpen` skill (github.com/cursor/plugins, pstack/skills/sharpen, commit 190d287, MIT License, (c) 2026 Lauren Tan).

The goal is a deeper version of the task, not a bigger one. Before rewriting the task or prompt, do four things:

1. Say what a top professional in this field would do here that the request isn't asking for.
2. Name the rawest material they would start from instead of what has already been digested (primary sources, raw data, original docs, real user behavior).
3. Name the specific methods and tools they would use.
4. Say what, other than the requester or the agent, would show the result is right (an outside check: real data, a test, a market signal, an expert source).

Then rewrite the prompt to ask for exactly that.

Leave choices that belong to the requester open instead of deciding them. Don't widen scope, add deliverables, or raise cost without saying so.
